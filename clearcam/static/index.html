First-time Linux setup

Install v4l2loopback-dkms and matching kernel headers. Then run:

sudo modprobe v4l2loopback video_nr=10 card_label=Clearcam exclusive_caps=1

Select Clearcam as the camera in your call. Setup details are in the project README.
