First-time Linux setup

Install v4l2loopback-dkms and matching kernel headers. Then run:

sudo modprobe v4l2loopback video_nr=10 card_label=Offscene exclusive_caps=1

Select Offscene as the camera in your call. If the device still says Clearcam, follow the rename steps in the project README; loading an already-loaded module does not change its label.
